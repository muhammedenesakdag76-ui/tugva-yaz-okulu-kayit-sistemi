# TÜGVA Yaz Okulu Kayıt Sistemi

Firebase tabanlı kayıt sistemi.

## Özellikler

- ✅ T.C. Kimlik doğrulama
- ✅ Aynı T.C. ile tekrar kayıt engeli
- ✅ 85 kişilik kontenjan
- ✅ Canlı kalan kontenjan
- ✅ Yönetici paneli
- ✅ Kayıt arama
- ✅ Kayıt silme
- ✅ Excel'e aktarma
- ✅ QR Kod oluşturma
- ✅ Mobil uyumlu

## Kurulum

1.

Firebase projesi oluştur.

2.

Firestore'u etkinleştir.

3.

Rules dosyasını yayınla.

4.

firebase.js içerisine kendi Firebase bilgilerini gir.

5.

Projeyi GitHub Pages veya Firebase Hosting'e yükle.
